# 17. Словарь и идентификаторы

**ID:** GLOSSARY · **Версия:** 0.1.0 · **Статус:** ACCEPTED для смысла; английские обозначения — PROPOSAL для данных.

Русские имена используются в интерфейсе и документации. Английские идентификаторы предназначены для данных; это договор о терминологии, не обязательный список классов Godot.

| Термин | Идентификатор | Значение |
|---|---|---|
| Кампания | `campaign` | История одной души в одном продолжающемся мире |
| Душа | `soul` | Постоянный носитель личных достижений, знаний и конечного срока |
| Тело, оболочка | `body` | Текущий физический персонаж со своей биологией и культивацией |
| Переселение | `reincarnation` | Переход души после гибели в новое пригодное тело; в тексте допустимо «перерождение» |
| Годы души | `soul_elapsed_years` | Время после первого игрового вселения, а не неизвестный возраст древней души до ранения |
| Предел души | `soul_lifespan_cap_years` | Общий достигнутый потолок существования души; не число новых лет, выдаваемых при каждом прорыве |
| Возраст тела | `body_age_years` | Биологический возраст текущей оболочки |
| Предел тела | `body_lifespan_cap_years` | Потолок жизни, поддерживаемый текущим телом и его стадией |
| Остаток жизни | `remaining_years` | Разница соответствующего предела и возраста/прошедшего срока |
| Мировая дата | `world_year` | Дата в истории мира; может начинаться не с нуля |
| Год кампании | `campaign_year` | Прошедшие календарные годы после старта этой кампании |
| Эпоха | `epoch` | Авторский набор исходных условий мира для старта |
| Seed | `world_seed` | Начальное значение воспроизводимого выбора допустимого состояния мира |
| Рубеж | `milestone` | Конкретная подстадия конкретной стадии, которую душа могла уже достичь раньше |
| Конденсация ци | `qi_condensation` | Первая большая стадия |
| Установление Основания | `foundation_establishment` | Вторая стадия; сокращённо «Основание» |
| Формирование Ядра | `core_formation` | Третья стадия; сокращённо «Ядро» |
| Зарождающаяся душа | `nascent_soul` | Четвёртая стадия; не отдельная от игровой души сущность данных |
| Божественная трансформация | `divine_transformation` | Цель базовой игры |
| Ранняя / средняя / поздняя / Великое совершенство | `early` / `middle` / `late` / `perfection` | Единая сетка подстадий первых четырёх стадий |
| Культивация | `cultivation_progress` | Накопление в ходе практики; не награда XP за убийство |
| Понимание метода | `method_understanding` | Знание способа развития; отличается от физической готовности |
| Устойчивость | `stability` | Пригодность тела и ци к выбранной практике |
| Малый прорыв | `minor_breakthrough` | Переход между подстадиями одной стадии |
| Великий прорыв | `major_breakthrough` | Переход между большими стадиями |
| Длительное действие | `long_action` | Явно подтверждаемая операция, расходующая календарные годы |
| Уединение | `retreat` | Длительная практика; «отступление» в бою обозначается отдельно |
| Отход из боя | `combat_escape` | Действие для спасения тела с реальными требованиями и риском |
| Отпечаток знания | `knowledge_imprint` | Сохранившаяся основа глубоко освоенного знания |
| Датированное знание | `dated_knowledge` | Запись с моментом наблюдения и возможной устарелостью |
| Источник ресурса | `resource_node` | Конкретный объект мира до и после добычи |
| Происхождение | `origin_properties` | Возраст, зрелость, природный потенциал материала |
| Состояние материала | `condition_properties` | Целостность, чистота и сохранённая энергия |
| Травничество | `herbalism` | Распознавание и работа с растительными ресурсами |
| Алхимия | `alchemy` | Переработка, пилюли и квалификация работы с минералами, кровью, костями и эссенциями |
| Обострённые чувства | `heightened_senses` | Физические признаки среды |
| Духовное восприятие | `spiritual_perception` | Концентрации и потоки ци |
| Чувство жизненной силы | `vital_sense` | Состояние живых тканей и остатков |
| Проникающее духовное зрение | `penetrating_spiritual_sight` | Внутренняя структура и энергетические оболочки |
| NPC-личность | `npc_person` | Конкретный человек со своим возрастом и отношением |
| Роль | `world_role` | Позиция торговца, наставника или старейшины, которую могут занимать разные люди |
| Организация | `organization` | Секта или другой институт, способный сохранять договоры и историю |
| Личное поручение | `personal_quest` | Обещание конкретного человека с условиями прекращения |
| Институциональный договор | `institutional_contract` | Обязательство организации, живущее по явно указанным условиям |
| Приглашённый старейшина | `guest_elder` | Договорный защитник с ограниченными благами и обязанностями |
| Полная тактическая пауза | `tactical_pause` | Остановка боевого исполнения с выбором следующего действия |
| Первый игровой срез | `vertical_slice` | Малый сквозной фрагмент, соединяющий ключевые системы |

«Человеческий / земной / небесный путь», «ложный корень» и нумерация слоёв из других игр не становятся обязательными механическими категориями этого проекта. Если эти слова вводятся в контент, их смысл должен быть задан отдельно.
