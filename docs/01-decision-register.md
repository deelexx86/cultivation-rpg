# 01. Реестр решений и приоритет источников

**ID:** DECISIONS · **Версия:** 0.3.0 · **Статус:** ACCEPTED для перечисленных решений; новые уточнения выделены.

Этот документ фиксирует смысл принятых решений. Детальная спецификация находится в указанном основном документе. Реестр не объявляет проверенным балансом числа из примеров.

## Источник и порядок применения

Источник — последовательные решения пользователя в обсуждении проекта и принятие полной истории «Белая осока». Имена NPC, даты и исходы этой истории приняты как **один эталонный маршрут**, без требования воспроизводить его в каждой кампании.

Последнее явное решение пользователя имеет высший приоритет. Следом используются этот реестр и профильная спецификация. Если они расходятся по существу, агент описывает расхождение и исправляет документацию в рамках полномочий текущей задачи; не вводит собственное скрытое правило.

Новые детали интерфейса, порядка обработки событий, структуры данных, художественного направления и декомпозиции разработки впервые сформулированы при подготовке пакета. Они помечены **PROPOSAL**. Числа имеют статус **HYPOTHESIS**, если не обозначают арифметику конкретного эталонного примера.

## Чего принятие не означает

Принятый диапазон сроков жизни — рабочий пример со стадиями, а не окончательный математический закон удвоения. Принятие кампании с двумя телами не вводит квоту смертей. Возможность сохранения знания не фиксирует проценты переноса. Предложение случайной генерации не разрешает генератору нарушать жизнеспособность базовых маршрутов.

Полные числовые оговорки — в [балансе](11-balance-and-pacing.md), неполные решения — в [реестре OPEN](16-open-questions-and-risks.md).

## Регистрация изменения

Новый принятый смысл получает новую запись либо явную поправку к существующей: причина, изменённые правила, влияние на сохранения и контент, способ проверки. Старый смысл отмечается как заменённый. Дата сама по себе не делает предложение принятым — основанием служит решение пользователя либо явно делегированная ему область. [Шаблон изменения](../templates/design-change.md).
